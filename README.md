# Logistics & UI Design Patterns

Console Java application implementing **Factory Method** (logistics delivery) and **Abstract Factory** (multi-platform UI components) design patterns.

## Prerequisites
- Java JDK 17+
- Maven

## Build & Run
1. Compile the project:
   ```bash
    mvn clean compile

2. Run the application:
    ```bash
    mvn exec:java -Dexec.mainClass="assignment2.Main"

Supported Inputs

Delivery Mode: [ROAD, SEA]

UI Platform: [WINDOWS, MACOS]
